# sez.im — бэкенд v2

Платформа подбора психологов и онлайн-сессий (Казахстан). Замена версии на Bubble.

## Ключевые решения

- **Сначала время, потом психолог.** Клиент заполняет анкету без регистрации, видит календарь только тех окон, где есть подходящие специалисты, и выбирает из свободных.
- **Сетка из 30-минутных ячеек.** Индивидуальная сессия 50 мин (2 ячейки), парная 80 мин (3 ячейки).
- **Двойная запись невозможна:** `EXCLUDE USING gist` по интервалу записи в PostgreSQL.
- **Холд на 15 минут** на время оплаты; вход по OTP только на шаге оплаты.
- **Платежи:** Robokassa, FreedomPay, Kaspi (адаптер ждёт спецификацию), внутренний баланс и подарочные сертификаты. Все движения денег — через журнал `ledger_entries`.
- **Видео:** LiveKit self-hosted, токены только участникам и только в окне сессии, фиксация входа.

## Стек

Python 3.10+, FastAPI, SQLAlchemy 2 (async), PostgreSQL 16, Redis, arq, LiveKit, Docker Compose.

## Быстрый старт

```bash
cp .env.example .env            # заполнить пароли и ключи
docker compose up -d --build
docker compose exec api python -m app.init_db
```

API: `http://127.0.0.1:8000/docs`. Воркер (холды, сетка, напоминания) запускается отдельным контейнером.

## Структура

```
app/
  main.py              точка входа, обработка доменных ошибок
  models.py            ORM-модели
  schemas.py           Pydantic-схемы
  routes/              клиент, кабинет психолога, вебхуки
  services/            подбор, доступность, запись, баланс, сертификаты, видео
  payments/            адаптеры платёжных провайдеров
  worker.py            фоновые задачи arq
tests/
  e2e_flow.py          сквозной сценарий (22 шага)
  bench_queries.py     замер ключевых запросов
  load_http.py         нагрузочный тест через HTTP
  seed_load.sql        данные для нагрузки (1000 психологов, 8 недель)
```

## Производительность

1000 психологов, 1,05 млн ячеек расписания, 184 тыс. записей; 1 vCPU, 3 ГБ RAM.

| Операция | p50 |
|---|---|
| ЛК психолога, неделя | 1,4 мс |
| Слоты психолога, 2 недели | 3,7 мс |
| Запись (холд) | 12 мс |
| Подборка на вечер | 15 мс |
| Календарь, 14 дней | 4 мс из кэша / 130 мс без кэша |

Воспроизвести: `psql -d sezim -f tests/seed_load.sql && python tests/bench_queries.py`.
